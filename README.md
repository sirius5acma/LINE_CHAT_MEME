# 💬 社群專屬幹話 / MEME 產生器

這是專為我們社群打造的聊天紀錄檢視與 MEME 截圖工具！
收錄了群組內的歷史對話，讓大家可以隨時挖古董、找回憶，並一鍵把經典幹話變成高品質梗圖。

## ✨ 怎麼玩？（功能指南）

- 🔍 **找梗（智慧搜尋）**
  在左上方輸入關鍵字或暱稱，按下 Enter 就能搜出所有相關的歷史名言。

- ⏱️ **還原現場（長按時光機）**
  在搜尋結果中，看到某句話覺得很好笑但忘記前因後果嗎？
  👉 **長按那則訊息（直到橘色圈圈轉滿）**，系統就會直接帶你搭時光機，跳轉回該句話發生的原始月份與上下文，並高光閃爍提示！

- 📸 **做圖（MEME 截圖模式）**
  1. 點擊左上方的「📸 開啟 MEME 截圖模式」。
  2. 點選你想做成梗圖的對話（可多選，對話框會反白）。
  3. 點擊右下角的「⬇️ 下載已選取的截圖」。
  4. 系統會自動幫你補上日期，並匯出一張完美還原 LINE 樣式的截圖！

---

## ⚠️ 溫馨提醒與社群規範 (必讀)

1. **僅供娛樂，請勿走心**：
   本工具的初衷是為了讓大家方便產出社群內部的 MEME，搏君一笑，回味大家的經典語錄。

2. **嚴禁惡意使用**：
   請勿利用本工具產生的截圖，刻意去脈絡化、斷章取義來抹黑、攻擊他人，或用於任何惡意造謠及引戰行為。

3. **注意隱私界線**：
   產生的 MEME 若包含他人的敏感個資（如真實姓名、私密照片等），請務必自行打碼，或在發佈至外部公開平台前取得當事人同意，共同維護社群友善環境。

> **玩得開心，製圖愉快！**
